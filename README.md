# Вместо Кекса — сайт и CRM ресторана

Проект индивидуального русскоязычного сайта ресторана в Ставрополе, с меню, бронированием, CRM, Telegram и измеримой эффективностью. Пробный период — 14 дней с фактического публичного запуска и размещения ссылок, по согласованным с рестораном условиям.

## Локальный запуск

Требуются Node.js 24 LTS и pnpm 11.25.0. Каркас использует Next.js 16.4.6, React 19.3.1 и TypeScript 6.0.3. Зависимости зафиксированы в `pnpm-lock.yaml`. Прототип запускается без переменных окружения.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте [главную страницу](http://127.0.0.1:3000). Сервер принимает соединения на `127.0.0.1`. Меню доступно по `/menu`, завтраки по `/breakfast`, афиша по `/events`. Локальный пример карточки и страницы события доступен по `/preview/events`. Для проверки собранной версии выполните `pnpm build`, затем `pnpm start`.

## Проверки

```sh
pnpm lint
pnpm typecheck
pnpm build
pnpm test:e2e
```

`pnpm test` запускает тот же браузерный набор. На Windows Playwright использует установленный Microsoft Edge, если он доступен. Для установки браузера Playwright выполните `pnpm exec playwright install chromium`. Результаты этапа и скриншоты указаны в [PROGRESS.md](PROGRESS.md).

## Источники и ограничения
Позиции, выход и цены сверены с печатным меню ресторана. Фирменные материалы перечислены в реестре ассетов. Адрес, телефон, часы работы и подачи завтраков, сведения об аллергенах, план столиков и расписание событий требуют подтверждения перед запуском. Не публиковать демонстрационные сведения как реальные. Репозиторий приватный, но это не хранилище секретов или персональных данных.

Текущее состояние реализации описано в [журнале проекта](PROGRESS.md).
